# Adresverkenner

Eén pagina die voor een Nederlands adres bouwkenmerken, WOZ-waarde, dakoppervlak (met 3D-model),
adressen in hetzelfde pand, buurtgegevens en klimaatrisico's toont.

Dit is de frontend (statisch, één `index.html`), gehost op GitHub Pages. Aanvullende gegevens
komen via aparte proxy's op adresverkenner.nl en staan niet in deze repository.
